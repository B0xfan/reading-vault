# Fonts

Every font Reading Vault uses is embedded in `styles.css` (base64
`@font-face`), so the plugin never loads a font from the internet. All four
are under the SIL Open Font License 1.1, which allows bundling them with
software, including software that is sold. Each licence file below carries
that font's own copyright line.

| Font | Used for | Licence file |
|---|---|---|
| Fraunces | book text (default "Serif") and headings | `Fraunces-OFL.txt` |
| Work Sans | the "Sans" book font and some interface text | `WorkSans-OFL.txt` |
| IBM Plex Mono | small labels and numbers | `IBMPlexMono-OFL.txt` |
| Atkinson Hyperlegible | the "Easy-read" book font | `OFL.txt` (the `.woff2` files are here too) |

Sources: the licence texts are copied unchanged from the fonts' published
copies in the Google Fonts repository (`google/fonts`, `ofl/<family>/OFL.txt`).
