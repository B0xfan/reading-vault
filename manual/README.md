# Reading Vault user manual

Hi, I'm John. I made Reading Vault because I wanted my books and my notes in the same place. Reading Vault lets you read EPUB and PDF books right inside Obsidian. Everything you highlight and write becomes a regular note in your vault.

This manual has one short page for each feature. Read them in any order.

![The Library with a few books on the Grid tab](images/library.png)

## Good to know

- Reading Vault works in Obsidian on desktop computers only, not on phones or tablets. Tested on Mac; Windows is untested.
- Nothing is hidden in a private database. If you stop using Reading Vault, your books, highlights and notes all stay in your vault.
